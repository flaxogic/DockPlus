Capabilities

Designed to feel built into macOS

Every panel, transition, and menu mirrors the macOS Dock — extended cleanly across workflows and displays.

Multi-Dock

Unlimited Independent Docks

Build dedicated docks for Coding, Comms, Design, or client projects. Each dock stores its own apps, files, folders, separators, icon size (32–80 pt), magnification scale (1.15×–2.0×), orientation, edge placement, and hardware display UUID pin.

QuartzCore SDF

Always-Active Liquid Glass

Powered directly by QuartzCore's GPU Signed Distance Field pipeline on macOS 26/27 for real-time refraction and specular rims — staying crystal-clear even on non-key floating panels, with automatic NSVisualEffectView fallback on macOS 14–25.

Open Apps

Live Unpinned Running Apps

Designate one dock in Manage Docks (⌘M) to show unpinned running apps behind a separator via instant NSWorkspace notifications. Right-click any open app and choose Options ▸ Keep in Dock to pin it.

Placement

Move Mode & Magnetic Snapping

Avoid accidental drags when launching icons. Enter Move Mode, drag within 24 pt of any screen edge to snap magnetically and auto-flip Horizontal ↔ Vertical orientation, then press Esc or click Done.

Auto-Hide

Invisible Edge Auto-Hide

Edge-snapped docks with auto-hide enabled slide completely off-screen at 0% opacity — leaving zero stray glass sliver — and spring back smoothly when your cursor hits a silent 2 pt trigger strip.

System Integration

Reversible System Dock Suppression

Want Dock+ front and center without uninstalling anything? Enable Disable system Dock in Settings (⌘,) to suppress the built-in macOS Dock while keeping Mission Control, Spaces, Wallpaper, and ⌘⇥ intact. Your exact previous macOS Dock settings restore automatically on toggle off or quit.

Get Started

Right-click DockPlus.app → Open on first launch, or clear Gatekeeper quarantine in Terminal:

03

Customize via Menu Bar

Click the Dock+ icon in your menu bar, press ⌘M for Manage Docks, or ⌘, for Settings.

⌘N New Dock ⌘M Manage ⌘Z Undo ⌘, Settings

Build from Source

Requires macOS 14.0+ and Xcode 16+. Zero CocoaPods, Swift packages, or paid signing certificates required.

git clone https://github.com/flaxogic/DockPlus.git
cd DockPlus
open DockPlus.xcodeproj

Select the DockPlus scheme and press ⌘R to run or ⌘U to run tests.

xcodebuild -project DockPlus.xcodeproj -scheme DockPlus -configuration Debug -destination 'platform=macOS' test
xcodebuild -project DockPlus.xcodeproj -scheme DockPlus -configuration Release -destination 'generic/platform=macOS' build

Outputs an ad-hoc signed universal binary (arm64 + x86_64) ready to launch.

FAQ & Limitations

Transparent by design

What macOS allows cleanly without Accessibility hacks — and how Dock+ handles edge cases.

Does Dock+ remove or replace the built-in macOS Dock?

No utility can safely uninstall Apple's Dock.app because it also powers Mission Control, Spaces, Desktop Wallpaper, and ⌘⇥. Instead, Dock+ runs cleanly alongside it — and offers an optional Settings → Disable system Dock toggle that suppresses the built-in Dock while Dock+ runs and automatically restores your exact settings on quit.

Why does macOS show an unverified developer prompt on first launch?

Prebuilt releases are currently ad-hoc signed rather than notarised with a paid Apple Developer ID. Right-click DockPlus.app and choose Open once, or run xattr -dr com.apple.quarantine /Applications/DockPlus.app. You can also inspect and build the entire app yourself from Xcode.

Why aren't notification badges shown on dock icons?

macOS does not expose Mail, Messages, or third-party app Dock badge counts to sandbox-friendly or permission-free apps. Avoiding private badge scraping keeps Dock+ fast and 100% free of Accessibility or Full Disk Access prompts.

What happens when an external monitor disconnects or uses DisplayLink?

A dock pinned to a specific display UUID stays hidden while that monitor is disconnected and reappears automatically when it returns. Because some DisplayLink adapters or USB-C hubs report a different UUID across reconnects, set a dock's Display to Primary Display in Manage Docks (⌘M) if it loses its pin.

Where is my configuration stored?

All docks, items, and preferences live locally in ~/Library/Application Support/DockPlus/docks.json. Before every atomic save, Dock+ saves a backup at docks.json.bak for automatic recovery. Nothing ever leaves your Mac.
